# JavaScript Objects for QA

Practical exercises covering JavaScript objects in a QA context.

## Session 1 — Fundamentals

Topics:

- Object properties
- Dot and bracket notation
- Nested objects
- Arrays of objects
- Methods and `this`
- Adding objects with `.push()`
- `forEach()` and `filter()`

Exercises: `01`–`07`

## Session 2 — Working with Object Data

Topics:

- `find()`, `some()`, `every()` and `map()`
- `Object.keys()`, `Object.values()` and `Object.entries()`
- Object destructuring

Planned exercises: `08`–`12`

## Session 3 — Copying and Combining Objects


Topics:

- Spread syntax
- Objects passed to functions
- Object references
- Final QA-focused practice

Planned exercises: `13`–`16`
